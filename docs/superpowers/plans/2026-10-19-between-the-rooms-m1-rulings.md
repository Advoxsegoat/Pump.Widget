# Between the Rooms M1: rulings and deferred minors

Every decision taken on the owner's behalf while building M1 (`docs/superpowers/plans/2026-10-19-between-the-rooms-m1.md`), in the order made, each as *what was decided — why — what it costs if wrong*. Then the final review's fixes and the minor findings left for later.

## Rulings

- **Pre-flight.** T8 sight uses `AD.world && AD.world.sightRange ? AD.world.sightRange(room,x,y) : 8` — T10 lands later and must not break T8 — cost if wrong: one call site.
- **Task 1.** suite command is `npm test` (node --test tests/*.test.mjs) — Node 22 runs a bare directory argument as a file — cost if wrong: none, same tests
- **Task 3.** plan's expected walking distance to (4,3) was 3; it is 5 (path round the wall end, diagonals may not cut corners, worked by hand) — the spec's no-corner-cutting rule decides it — cost if wrong: one assertion
- **Task 4.** plan's blocked-step test stepped into a free tile (7,4); rewritten to step diagonally into the tile m claimed (7,5) — the intent (no two bodies per tile) is the spec's — cost if wrong: one assertion
- **Task 6.** proc coefficients the spec leaves open — Throwing Knives 0.5, Bell Chime 0.5, Brass Moon spark 80% at 0.2 (as Spark Coil) — keeps chains short without making procs dead — cost if wrong: balance numbers only
- **Task 7.** regen is applied a fraction per frame, so a second of Get Up also carries a second of regen (24 HP after 1 s, not 23) — spec gives both regen and Get Up; neither pauses the other — cost if wrong: 1 HP.
- **Task 7.** a roll cancels an attack in wind-up or recovery but never during its active frames — spec silent; GBA-feel and fairness — cost if wrong: feel only
- **Task 8.** lunging attacks (grunt, hound, whelp) are a 2-tile line that carries the attacker 1 tile forward on the strike; ranged shots fly at any angle, the fusilier's musket only along 8 lines — spec gives frames and reach, not geometry — cost if wrong: feel only.
- **Task 8.** a whelp may strike from over a pit (flyer) — the plan's test expected it to land past the pits — cost if wrong: one assertion
- **Task 9.** waves = 1 below a 40-credit budget, 2 below 80, else 3; an elite whenever affordable from depth 3 (as the spec words it) — spec fixes 'up to three' and the elite rule — cost if wrong: tuning
- **Task 10.** the hero moves in a 'hero' mode that may enter pits (Zelda); monsters' 'walk' never does — spec says pits cost the hero 10% and return them, which needs the hero able to enter one — cost if wrong: one mode name
- **Task 10.** closed doors are treated as walls by gas (the spec's 10% leak would only matter across rooms, which M1 never simulates together) — cost if wrong: gas never leaks under a sealed door
- **Task 10.** environmental fire burns at 4% of max HP a second (spec gives no number); a trap spike is 60% of a 20-damage trap base, level-scaled; an explosion never hurts the body that made it — cost if wrong: balance only
- **Task 11.** the exit room keeps type 'exit' on boss depths (F.bossDepth marks it; the arena is a separate room the gate opens onto) — plan said type 'boss'; spec says the gate opens onto the arena — cost if wrong: a type name
- **Task 11.** the secret room is never placed beside the treasure room either, so a secret door can never bypass a locked treasure door — spec only forbids the exit — cost if wrong: fewer secret-room slots
- **Task 11.** room templates are authored as 13x8 interiors with door mouths (7,1),(7,8),(1,4),(1,5),(13,4),(13,5) always floor, so a vertical flip keeps side doors usable — cost if wrong: none
- **Task 12.** rooms with nothing to fight (start, treasure, rest, secret, exit) count as cleared on entry — the plan's test said the start room is 'entered'; nothing distinguishes the two for a room that never seals — cost if wrong: a state name
- **Task 12.** each room gets its own event bus that forwards to the run's — avoids listeners piling up room after room; sound, HUD and saves listen on the run — cost if wrong: none
- **Task 12.** a chest in a locked treasure room is free (the key was its price); other chests cost chestCost(25 or 50) — spec gives the prices but also says a treasure room can sit behind a key — cost if wrong: economy
- **Task 12.** each room's layout is drawn from a stream seeded by (seed, depth, room key), not from the shared layout stream, so visiting rooms in a different order never changes them (needed for saves and replays) — cost if wrong: none

## Final review fixes

- a cracked wall blown open left the secret room's own side walled ('%'), trapping the hero; it now opens the floor's link on both sides like a key, and comes up barred while the room is sealed — tests 'a cracked wall bombed open is a door both ways' and 'a cracked wall blown open in a sealed fight stays barred until the room is clear' RED->GREEN
- a Page of Teleport could leave a sealed fight or the arena, and a resume then brought the room back barred with no fight in it — the page is read (used up, named) but the Seams hold the hero there, with a notice; on load any room left before it was cleared is met fresh, what was taken there staying taken — tests 'a Page of Teleport cannot carry the hero out of a sealed fight or the arena' and 'a room left before it was cleared comes back fresh on a resume' RED->GREEN
- the hero's item and Get Up handlers were installed again on every re-entry into a room (Warm Mitts 21 -> 48 after three returns) — installed once per room and hero — test 'walking back into a room does not stack the hero's items' RED->GREEN
- Taffy, the combo reset and the hurt pose compared stamps from the last room's clock with the new room's — the hero's stamps shift onto the new room's clock as it enters — test 'timers the hero carries count on through a door' RED->GREEN
- a failed Garden save used up the run's one-time storage notice — it is noted on its own flag — test 'a Garden save that fails does not use up the run's notice' RED->GREEN
- a finger whose lift never arrived (a paused WebView) kept a touch button held after the page came back — finger tracking moved to AD.input.touchDown/touchUp and cleared by releaseAll — test 'a finger whose lift never arrived leaves nothing held' RED->GREEN
- the chest reroll (an 80-petal unlock) was all but unusable: the chest's item dropped under the hero and was taken in 10 frames — it now lies beside the chest — test 'a chest's item lies beside the chest, not under the hero' RED->GREEN
- Magic Mapping, the Pocket Bell and Mind Vision set state nothing read — run.knownRooms() (visited, seen through doors, every room with the Bell, the secret one too with Mapping) and run.foeRooms() (while Mind Vision lasts) now drive the minimap and the map; 'revealed' resets each depth and is saved — tests 'the map knows what the hero has seen...' and 'Mind Vision shows where the monsters are on the floor for 30 s' RED->GREEN
- the third quickslot (a 40-petal unlock) had no place on the phone's HUD — quick2 sits left of the other two, is drawn when unlocked and takes taps through AD.hud.quickAt — test 'the third quickslot, once unlocked, has a place of its own on screen and takes taps' RED->GREEN
- Upgrade never asked what to upgrade and spare armour could not be worn or taken off — AD.cons.choices / toggleArmour (tested), a 'which?' chooser from the Items screen and from a quickslot, spare pieces listed in Items (A wears one, A on the worn piece takes it off, a cursed piece stays) — tests 'a Page of Upgrade asks what to upgrade once there is armour to choose' and 'spare armour can be worn, and armour taken off, unless the worn piece is cursed' RED->GREEN; driven in Chromium with real key presses

## Deferred minors

- AD.paused is set in any scene but cleared only by Play, so backgrounding on the Garden starts the next run paused (and in Pause, the menu reopens after Resume)
- persistent attacks die with their owner during the wind-up (an Ivory elite's death burst never fires; killing a bomber defuses its bombs)
- the gate always restarts on resume even when open, so leaving, quitting and resuming can farm a second guardian item and 3 petals
- the 40-alive cap is bypassed by a room's sleeping first wave and by boss summons (only at unrealistic clocks)
- gate waves take only plan()[0], so past a gate budget of 40 each wave gets a half (then a third) of the spec's budget
- typed seeds do not round-trip (hashed above SEED_MAX; use % SEED_MAX)
- fire does not open cracked walls (spec 6.6 says bombs, Powder Barrel and fire do)
- a Page of Teleport from a cleared room is used mid-run.tick, so the rest of that tick runs on the old room with the new coordinates
- when the door mouth is occupied the hero is placed on any free tile in the room, possibly mid gate-fight
- an unreadable meta save is set aside without the plain message a run save gets
- a dead ternary at run.js (openChest region)
- the 'clock stops while paused' test pins run.paused, a flag the real pause (the scene stack) never sets
